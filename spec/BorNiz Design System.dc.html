01 — Brand

Sell fast.
See everything.

BorNiz is a cloud POS for F&B, retail and service businesses in Indonesia, from a single warung to a franchise network. The system is built for the counter first: big touch targets, high contrast, one orange that always means "the next action".

03 — Typography

SF Pro, Apple's system typeface

SF Pro Display handles headlines, prices, totals and timers, always with tabular figures. SF Pro Text handles body copy and UI labels. SF Mono is for order IDs, SKUs, OTPs and codes. All three load from the operating system. Apple devices render SF; Windows and Android fall back to Helvetica Neue or the native sans.

Soft corners, firm edges

10 — Motion

Snappy by default

Press feedback starts within 80ms. Most transitions run 140–200ms. Only payment success and order arrival get an overshoot spring, so they stand out. Exits run faster than entrances. With prefers-reduced-motion, movement becomes a 120ms opacity fade.

Duration & easing tokens
{{ m.name }} {{ m.value }} {{ m.use }}
M1 · Press scale .96 on pointer-down, 80ms standard. Releases on pointer-up, 140ms.
M2 · Panel / drawer Enters in 320ms with emphasized-decelerate. Exits in 200ms with accelerate. The scrim fades to 40%.

M3 · Order arrives The toast drops 16px from the top with a spring and plays the order chime. It stays 5s and leaves upward in 160ms.
M4 · Count-up KPI numbers count up over 700ms on first view and on refresh. Never on every live tick. {{ kpiText }}

13 — Voice & copy

Say it like the shift lead

Short, direct and kind. English is the default and Bahasa Indonesia is a full, first-class translation. Buttons are verbs in sentence case. Prices are written IDR 25,000 in the UI and IDR 2,4 jt in charts. Speak to the user as "you" in English and "Anda" in Indonesian, or "kamu" in the self-order app.
